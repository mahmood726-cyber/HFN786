# cnma 1.0.0

## Initial Release

* First public release of cnma package
* Comprehensive network meta-analysis functionality
* Frequentist and Bayesian approaches supported
* Transportability analysis with multiple distance metrics
* GRADE and RoB2 weighting schemes
* Extensive diagnostic capabilities
* Meta-regression with spline support
* Publication bias assessment
* Interactive and static visualization options
* HTML report generation
* Complete test suite and documentation

## Key Features

* `run_cnma_analysis()`: Main analysis function
* `setup_cnma()`: Flexible configuration system
* `simulate_cnma_data()`: Demo data generation
* `cnma_parallel_on()`: Parallel processing support
* S3 methods for print, summary, and plotting

## Dependencies

* Core: netmeta, ggplot2, tidyverse packages
* Suggested: future, digest, rmarkdown, knitr
